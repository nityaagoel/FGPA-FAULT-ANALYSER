# ⚡ FPGA Fault Analyzer Dashboard

An interactive **Streamlit web app** to analyze FPGA/Verilog simulation results.  
It compares *golden* vs *faulty* outputs, detects mismatches, computes fault coverage,  
and visualizes bit-level errors using charts and metrics.

---

## 🚀 Tech Stack
- **Python**, **Streamlit**, **Pandas**, **NumPy**, **Matplotlib**
- Optional ML: **Scikit-learn**
- Simulation Data: Verilog-generated CSVs

---

## ⚙️ Features
✅ Upload `golden_output.csv` and `faulty_output.csv`  
✅ Detect mismatches and compute fault coverage  
✅ Visualize bit-error counts and match ratio  
✅ Optional ML-based fault severity classifier
